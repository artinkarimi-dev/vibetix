# VIBETIX — نسخهٔ کامل بدون کامنت در کد

این بسته بر اساس نسخهٔ کامل Stage 4 TLS Fixed ساخته شده است. کدهای JavaScript، TypeScript، React، CSS، HTML، SQL، Prisma و فایل‌های تنظیمات پروژه از کامنت خالی شده‌اند. متن‌های داخل رشته‌ها، نشانی‌های وب، و مستندات Markdown کامنت اجرایی نیستند و به‌قصد حفظ عملکرد و مستندات دست‌نخورده باقی مانده‌اند.

دو اصلاحی که روی لپ‌تاپ در همین گفتگو انجام شده بود در سورس اعمال شده است: مسیر search_path نقش مهاجرت دیتابیس، و مسیر PID در Nginx. فایل اختیاری docker-compose.host-build.yml و تنظیمات دانلود/کش pnpm نیز افزوده شده‌اند.

## هشدار مهم دربارهٔ دیتابیس موجود

حذف کامنت‌های فایل‌های SQL مهاجرت باعث تغییر هش SHA-256 آن‌ها می‌شود. Prisma برای Migrationهای قبلاً اعمال‌شده checksum نگه می‌دارد. بنابراین **این پروژه را بدون بررسی روی دیتابیس موجود جایگزین نکنید**؛ اختلاف هشِ مهاجرت‌ها ممکن است به‌عنوان تغییر تاریخچه تشخیص داده شود. برای کار روی دیتابیس واقعی از نسخهٔ فعال پشتیبان بگیرید و پیش از جایگزینی، وضعیت Migrationها را بررسی کنید. هیچ دستوری برای حذف دیتابیس یا پاک‌کردن Volume لازم نیست.

## اجرای محلی

اطلاعات حساس محلی مانند `.env.local` در بسته نیستند و نباید در GitHub قرار بگیرند. آن‌ها را از نسخهٔ فعالِ خودتان فقط در محیط محلی نگه دارید.

روی سیستم‌هایی که فقط با network: host می‌توانند Build انجام دهند، فایل docker-compose.host-build.yml به‌عنوان override اختیاری قابل استفاده است. entitlement شبکهٔ host باید هنگام Docker Build صریحاً مجاز شود.

## وضعیت کنترل کیفیت

۲۲ تست Node محلی روی سورس این بسته موفق شدند. بررسی نحوی فایل‌های JavaScript/TypeScript هم موفق شد. اجرای مجدد Docker و آزمایش زندهٔ PostgreSQL روی این بسته از این محیط انجام نشده است.
